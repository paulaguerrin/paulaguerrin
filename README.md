# Paula Guerrin

Portfolio de Paula Guerrin, pensado para [paulaguerrin.com](https://paulaguerrin.com).

Stack: Vite, React y TypeScript. El proyecto es un sitio estático que Vercel puede construir con `npm run build`.

La página inicial solo muestra el nombre, el subtítulo «Portfolio» y tres secciones vacías (Trabajo, Información y Contacto). No hay biografía, proyectos ni datos de contacto todavía.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

La salida queda en `dist/`.
